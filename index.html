Direccionamiento de Memoria x86

Modo Real vs Modo Protegido • Arquitectura de Computadores

Desde el nacimiento del procesador Intel 8086 con su bus de direcciones de 20 bits hasta la consolidación del modelo segmentado-paginado en 80386, la arquitectura x86 transformó el acceso a la memoria RAM: pasando de una aritmética plana sin privilegios a un ecosistema multinivel con tablas de descriptores (GDT/LDT), anillos de protección por hardware y memoria virtual.

Paradigmas de Traducción: Modo Real vs Modo Protegido

Contraste fundamental entre la simple aritmética de desplazamiento por bus cableado del 8086 y la indirección protegida basada en descriptores de 80386.

Modo Heredado • 8086 / MS-DOS Bus: 20 bits

Modo Real (16 bits)

La dirección de segmento se interpreta directamente como la dirección base física desplazada 4 bits a la izquierda en hardware.

1. Dirección de Segmento CS, DS, SS, ES 16 bits de ancho, almacena párrafo base.
2. Desplazamiento IP, SP, BP, SI, DI Dirección efectiva de 16 bits (0 a 64 KB).
3. Límite de Memoria 1,048,576 Bytes (1 MB) +64 KB HMA hasta 0x10FFEF con A20 activa.
4. Espacio Direccionable Segmentos Solapados Cada segmento empieza cada 16 bytes.
Fórmula de Dirección Física
Dirección Física = (Segmento × 16) + Desplazamiento
Equivalente a: (Segmento << 4) + Desplazamiento
Demostración Numérica Hexadecimal:
Entrada Segmento: 0x2000 Desplazamiento: 0x0150
Desplazamiento (×16 / shift) 0x20000 Añade 0h a la derecha
Dirección Física de 20 bits 0x20150
warning
Sin Protección de Memoria: Cualquier programa de usuario o puntero corrupto puede sobrescribir el vector de interrupciones (IVT en 0x00000), el código de la BIOS o el propio núcleo del sistema operativo.
Modo Avanzado • 80286 / 80386 Bus: 32 bits (4 GB)

Modo Protegido (Segmentado y Lineal / 32 bits)

Los registros de segmento ya no apuntan a la memoria directamente; son selectores que indexan estructuras de control (Descriptores) cargadas en RAM.

1. Selector de Segmento 16 bits: Índice + TI + RPL Apunta a una entrada específica en GDT/LDT.
2. Tablas de Descriptores GDT y LDT (GDTR / LDTR) Arreglo en RAM de hasta 8192 descriptores.
3. Descriptor de Segmento Estructura de 64 bits Base 32-bit, Límite 20-bit, Permisos y DPL.
4. Espacio Lineal 4,294,967,296 Bytes (4 GB) Convertible a físico por MMU Paginación.
Ruta de Traducción de Memoria Protegida
1 Selector en Registro CS/DS → Extrae Índice (13 bits)
2 Localiza entrada en GDT en GDTR.Base + (Índice × 8)
3 Desempaqueta Descriptor (64 bits) y obtiene Dirección Base de 32 bits
4 Dirección Lineal = Base (Descriptor) + Desplazamiento (32 bits)

Formato del Selector de Segmento (Registro CS, DS, SS, ES, FS, GS)

Un registro selector de 16 bits no contiene una dirección base; almacena tres campos que indexan la GDT/LDT e informan el nivel de privilegio solicitado.

Índice (13 bits) Bits 15 .. 3 Selecciona 1 de hasta 8,192 Descriptores en la tabla
TI (1 bit) Bit 2 0:GDT 1:LDT
RPL (2 bits) Bits 1..0 Nivel de Privilegio Solicitado: 0..3
format_list_numbered Índice [15:3]

Índice multiplicado implícitamente por 8 (tamaño de cada descriptor) para obtener el desplazamiento de byte exacto en la tabla GDT o LDT. Rango: 0 a 8191 (2¹³ entradas).

Rango: 0 a 8191 (2¹³ entradas)
table_chart TI [Bit 2]

Indicador de Tabla (Table Indicator): Especifica cuál tabla del sistema consultar. Si es 0, consulta la GDT global; si es 1, consulta la LDT local del proceso actual. 0 = Tabla GDT • 1 = Tabla LDT.

0 = Tabla GDT • 1 = Tabla LDT
security RPL [Bits 1:0]

Nivel de Privilegio Solicitado (Requested Privilege Level): Nivel de privilegio solicitado por quien invoca el segmento (Ring 0 Kernel, Ring 1/2 Drivers, Ring 3 Usuario). 00b = Ring 0 (Kernel) • 11b = Ring 3 (Usuario).

00b = Ring 0 (Kernel) • 11b = Ring 3 (Usuario)

Diferencias funcionales determinantes para el diseño de kernels, compiladores y sistemas operativos de arquitectura x86.
